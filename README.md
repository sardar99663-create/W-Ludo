# W-Ludo starter
Files: `index.html` (page), `style.css` (design), `game.js` (game logic and local save).

Upload all three files to the root of your GitHub repository. In GitHub open Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

This is an early playable prototype, not yet a fully verified commercial-quality Ludo implementation. Test rules and board layout before public launch. It uses browser localStorage for match persistence; full offline PWA caching/service worker can be added in a later iteration.
